# Project Board (Tasks & Milestones)

This file contains a task breakdown that you can copy into a GitHub Project board or use as issue templates.

Milestones
- MVP (Weeks 1-8)
  - Core driving feel (PlayerCarController tuned to grip-first drifting)
  - One prototype map (night downtown)
  - Player camera (Cinemachine) and engine audio hook
  - Wanted system and PoliceAI (basic pursuit)
  - Basic UI (speedometer, wanted meter)
  - Respawn/checkpoints

- Phase 2 (Weeks 9-16)
  - Add 3 additional maps (total 4)
  - Improve AI (PIT maneuvers, spike strips, roadblocks)
  - Simple progression (money, car shop placeholder)

- Phase 3 (Months)
  - Car shop, customization, and tuning
  - Expand car roster (placeholder models)
  - Optimization, streaming large maps

Suggested issues (copy into your Project/Issues)
- [ ] Setup repo & Unity project (packages: Input System, Cinemachine, URP)
- [ ] Add PlayerCarController script and tune basic parameters
- [ ] Add sample Player prefab with Rigidbody and collider
- [ ] Create prototype map (night downtown) using ProBuilder
- [ ] Implement Cinemachine Virtual Camera and speed-based FOV script
- [ ] Add WantedSystem and basic PoliceAI prefabs
- [ ] Implement RespawnManager and checkpoint placements
- [ ] Create UI: speedometer & wanted meter
- [ ] Profile & optimize physics settings

How to use
- Create a new GitHub Project (Beta or classic) named "Drive Fast Roadmap" and add the milestones above as columns or stages. Create cards for each suggested issue and assign them to milestones.
